วิธีใช้ GUPAN Agent

  1. พิมพ์คำสั่งภาษาไทยในช่องด้านล่าง แล้วกดส่ง
  2. โหมดเดโมจะจำลองการทำงานของเอเจนต์ให้ดูก่อน
  3. กด เข้าสู่ระบบ Puter มุมขวาบนเพื่อใช้ AI จริง (ฟรี ใช้โควตาบัญชีคุณ)
  4. แนบไฟล์ได้ด้วยปุ่ม Add files — ไฟล์อยู่แค่ในเครื่องนี้
  5. แชททั้งหมดเก็บในเบราว์เซอร์ เปิดดูย้อนหลังได้จากแถบซ้าย
