# GUPAN Blog — เว็บบล็อกแอป (HTML/CSS/JS ล้วน)

เว็บบล็อกที่**ใช้งานได้จริง** ไม่ใช่แค่หน้ากระดาษนิ่ง ๆ — เปิดอ่าน เขียน แก้ไข ลบ
ค้นหา คัดกรองหมวดหมู่ กดไลก์ บุ๊กมาร์ก คอมเมนต์ ได้หมด โดยไม่ต้องมีเซิร์ฟเวอร์

```
public/apps/blog/
├── index.html   # โครงหน้า: ฟีด + หน้าอ่าน + หน้าเขียน (สลับด้วย hash route)
├── styles.css   # ธีมมืดสไตล์ Bolt, mobile-first, ไม่มีเฟรมเวิร์ก
└── app.js       # แอปทั้งหมด: store, router, editor, markdown-lite — vanilla JS
```

## เปิดใช้

**วิธีที่ 1 — ดับเบิลคลิก:** เปิด `index.html` ในเบราว์เซอร์ได้เลย

**วิธีที่ 2 — static server:**

```bash
cd public/apps/blog
python3 -m http.server 8080 --bind 0.0.0.0
# เปิด http://localhost:8080
```

## ฟีเจอร์

- 📰 ฟีดบทความ + ค้นหา + หมวดหมู่ + เรียง (ใหม่/เก่า/ยอดนิยม)
- 📖 หน้าอ่าน: นับวิว, เวลาอ่าน, ไลก์, บุ๊กมาร์ก, คัดลอกลิงก์
- ✍️ หน้าเขียน: ใส่ปก emoji, แถบเครื่องมือ markdown-lite (`##`, `**หนา**`, `- รายการ`, ` ```โค้ด``` `, `[ลิงก์](url)`), ดูตัวอย่างก่อนเผยแพร่
- 💬 คอมเมนต์ทุกบทความ (เพิ่ม/ลบได้)
- 💾 เก็บทุกอย่างใน localStorage + ปุ่ม **สำรอง/นำเข้า JSON** + รีเซ็ต
- 📱 mobile-first: ปุ่ม FAB เขียนบทความ, รองรับจอ 360px ขึ้นไป

## เอาขึ้นเน็ตฟรี

โฟลเดอร์นี้เป็น static ล้วน อัปโหลด `index.html` + `styles.css` + `app.js`
(คงโครงโฟลเดอร์ไว้) ขึ้น Render Static Site / Cloudflare Pages / GitHub Pages /
Netlify Drop ได้ทันที ไม่ต้อง build
